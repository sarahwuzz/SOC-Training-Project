# Investigation Overview

This investigation documents the analysis of a simulated cyber attack against PT Nusantara Digital.

The investigation focuses on reconstructing attack chain using multiple security telemetry sources, and mapping to the MITRE ATT&CK framework.

The analysis begins with the reconnaissance phase identified from
the available telemetry and continues through initial access, execution, credential
access, discovery, persistence, lateral movement, collection,
exfiltration, and defense evasion.
